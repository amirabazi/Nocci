## Nocci 0.3.0

Nocci grows from a usage meter into a small home for your coding agents. Everything new
is off until you turn it on in Settings.

**Pull Requests.** Your open GitHub pull requests and GitLab merge requests, with CI
status, in the notch. Nocci asks your own `gh` and `glab`; it never sees a token. A Code
Review button on each row starts Claude Code or Codex on a review of that pull request
(experimental).

**Sessions.** A red dot on the notch when a Claude Code session needs your permission,
asks a question or finishes its turn, and a list of them one hover away. Click one to jump
to its terminal or editor.

**Projects.** Your project folders, most recently worked on first. Pick one, type what the
agent should do, and Nocci opens Claude Code or Codex there in Terminal, iTerm2, VS Code,
the Codex app, or Nocci's own terminal.

**Nocci's terminal (experimental).** Run agents in a Nocci window that drops down from the
notch, or right inside the notch itself. When a session there waits for you, answer it from
the Sessions list without leaving what you are doing. This is the newest part of Nocci and
the least tried, so it is marked experimental in the app; please report anything that
goes wrong in [GitHub Issues](https://github.com/amirabazi/Nocci/issues).

**A new look.** The notch is pure black now, opens on hover after a short pause (or
instantly, or only on click), can step aside for full-screen apps, and works on Macs
without a notch as a small pill.

**Smaller things.** Two optional global keyboard shortcuts, to open the notch and to go to
the session that needs you. Pull request notifications when someone asks for your review
or checks finish on your pull request, off by default. Usage history over 30 and 90 days,
and an Export CSV button. With Pace on, a small mark above each bar shows how much of the
window has gone. Numbers roll to their new value, and Nocci polls the pointer less often
while it is far from the notch.

### Worth knowing

- The first time Nocci opens, Settings shows you where to connect Claude Code and Codex.
- Nocci asks once whether it may check for updates automatically. Nothing is ever
  installed without asking.
- Claude usage comes from Claude Code in a terminal. The VS Code extension does not send
  it.
- Move Nocci to Applications before you connect anything; Nocci refuses to set up Claude
  Code from a temporary copy in Downloads.

### Before you install

This build is not signed with an Apple Developer ID, so macOS blocks the first launch.
Open **System Settings › Privacy & Security**, scroll to **Security**, and click
**Open Anyway**. You do this once.

Requires macOS 13 or later on Apple Silicon.
