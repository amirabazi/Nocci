## Nocci 0.2.0

The first public release under the name Nocci, replacing the earlier NotchUsage preview. Nocci puts your Claude and Codex subscription usage in the
notch, so you can see how much of an allowance is left without opening anything.

**Providers.** Claude Code and Codex are set up from Settings › Providers. Claude uses a
small bridge script that Nocci writes for you and can remove again; Codex reads your
installed executable. Each person connects their own account, and nothing is sent anywhere.

**Alerts.** Off until you turn them on. Each allowance can notify at levels you choose,
per provider, and reset alerts tell you when an allowance comes back.

**History and pace.** Optional local recording, with a native chart, and a quiet estimate
of whether an allowance will last until it resets. Both off by default.

**Presentation mode.** Hides the notch, its windows and its notifications for a set time,
then restores exactly what you had before.

Also: launch at login, a choice of used or remaining percentages, quick actions from either
notch menu, and a privacy-filtered Connection Details view that is safe to paste into a bug
report.

### Before you install

This build is not signed with an Apple Developer ID, so macOS will block the first launch
and say it cannot verify the developer. Open **System Settings › Privacy & Security**,
scroll to **Security**, and click **Open Anyway**. You do this once.

Requires macOS 13 or later. Tested on Apple Silicon; Intel Macs should build from source.
